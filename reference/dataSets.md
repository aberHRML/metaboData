# Available data sets for a given technique

Return a vector of available data sets for a given metabolomic
technique.

## Usage

``` r
dataSets(technique)
```

## Arguments

- technique:

  metabolomic technique name

## Value

A character vector of available data sets.

## Examples

``` r
if (FALSE) { # \dontrun{
dataSets(techniques()[1])
} # }
```
